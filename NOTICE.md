## Modifications

This repository reorganizes and adapts the original dataset for use as a Claude Skill, including:

- creating `SKILL.md` as the Agent instruction entry point;
- organizing university information into local reference files;
- adding an index for school lookup;
- adding `references/aliases.md`, an alias / abbreviation / former-name lookup index (3,157 unique entries), generated by `tools/build_aliases.py`;
- adding `tools/query.py`, a structured query and reverse-filter tool that classifies each answer within a question block instead of relying on literal `grep` matches;
- adding `tools/verify.py`, a data-integrity regression check;
- **redacting personal information** from the "数据来源" lists inside the per-school files: identifiers left by questionnaire respondents (mostly e-mail addresses) have been replaced with a stable pseudonym `实名反馈者 N`, where the same original identifier always maps to the same number. Questionnaire IDs (e.g. `A12345`) and submission timestamps are unchanged. The same redaction was applied to the archived data. `tools/redact.py` performs this idempotently;
- minor cleanups: removed a stray leading period from one school name in the index and in its file heading, and annotated three upstream identifiers (`tj`, `xn`, `swpu`) that could not be resolved to a real school name.

Data last refreshed from upstream on 2026-09-19 (generated branch `0abf14dfc897`, commit date 2026-09-19). Content was verified byte-identical to the previously synced 2026-07-07 snapshot apart from one upstream cosmetic difference (see below), so no bulk data change was needed. Includes both active data (3448 schools, responses from 2023-2026) and archived data (2705 schools, responses from 2021-2022, i.e. submitted before 2023-01-01).

## Privacy

The upstream generated data preserved identifiers that questionnaire respondents voluntarily provided, mostly personal e-mail addresses, in the "数据来源" list at the top of each school file. Because this repository is published publicly under CC BY-NC-SA 4.0, those identifiers have been replaced with stable pseudonyms (`实名反馈者 N`).

- Questionnaire IDs (`A12345`) and submission timestamps are unchanged, so a response can still be attributed to a single (pseudonymous) source and traced back to the upstream questionnaire ID.
- The mapping from original identifier to pseudonym is not published in this repository; the redaction is deterministic and reproducible through `tools/redact.py` for maintainers who need to re-run it after an upstream sync.
- No answer bodies were altered.

If you are the author of an upstream questionnaire response and want your entry removed entirely rather than pseudonymized, please open an issue.
