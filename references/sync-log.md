# 上游同步台账

记录每次从 [CollegesChat/university-information](https://github.com/CollegesChat/university-information) `generated` 分支同步的结果，便于下次同步判断增量范围。

同步操作步骤：

```bash
git clone --depth 1 --branch generated \
  https://github.com/CollegesChat/university-information /tmp/uci-upstream

# 1) 对比内容（本地已脱敏，需归一化后再比较）
# 2) 若有新增/变更文件，覆盖对应 references/ 文件
python3 tools/consolidate.py     # 归并上游错放条目（如校名字段填了说明文字）
python3 tools/redact.py          # 来源列表脱敏（幂等）
python3 tools/build_aliases.py   # 重建别名索引
python3 tools/patch_index.py     # 施加索引本地修正（日期、总数、瑕疵标注，幂等）
python3 tools/verify.py          # 完整性校验，期望 0 失败
# 3) 在本文件追加一条记录

> 注意：索引的本地修正已全部固化在 `tools/patch_index.py`。同步时若用
> `git checkout` 回退过 `references/index.md`，务必重跑该脚本恢复。
```

## 2026-10-04（第二轮：工具与隐私加固）

针对独立审计发现的问题做修复。上游数据本身无变更（`generated` 仍为 `0abf14dfc897`）。

**功能正确性**

- 删除 `build_aliases.py` 的「唯一子串包含」规则：它把 327 个**真实校名**变成指向别的学校的别名（如「上海交通大学」→「上海交通大学医学院」、「石河子大学」→「石河子大学护士学校」），而 `query.py` 先查别名，导致全称查询返回错误学校。另加两条护栏：派生别名若等于另一所真实学校全称则丢弃、汇总时再兜底过滤；`verify.py` 新增别名劫持检查守护该不变式。别名表由 3157 条重建为 **2829 条**（覆盖 2348 所学校），只丢失 327 条劫持与 4 条无意条目（`UPC`/`中石大` 及 2 条子串截断）。`build_aliases.py --check` 现在会比对现存 `aliases.md` 是否与生成结果一致。

- 修正 `query.py` 极性判定的词内误判：`不错`/`无线`/`发现`/`附近` 等会被当成否定或肯定信号（实测「很不错，基本全覆盖」被判 no、「有时很差」被判 yes）。新增 `NEUTRALIZE` 中性词剔除、计算肯定信号前先剥离否定短语、补充否定词（未/没）与分化词（有时/好像/勉强），并新增 `--selftest` 回归样例（14/14 通过）。
